Markets

Every number is a model's probability for the question's first option: Yes for yes/no questions (73% means "73% likely Yes, 27% likely No"), or the named option shown under the question, such as a team. Questions that belong to one multi-option event (e.g. "Which party wins the House?") are grouped under it, one row per option. The tag under each question is the real outcome once Polymarket settles it. After that, ✓ / ✗ show whether each model leaned the right way (above or below 50%). market is the Polymarket price when the models predicted: the crowd to beat. Click a row for details.

Podium

The three models with the lowest average Brier score on resolved markets. Brier is the squared gap between the probability a model gave and what happened (1 = Yes, 0 = No): 0 is perfect, 0.25 is what always guessing 50% scores. Accuracy is how often the model was on the right side of 50%.

Leaderboard

Ranked by Brier score (lower is better; always guessing 50% scores 0.250). Skill shows how far each model beats a coin flip.

Calibration

What a perfect line looks like

Predictions are grouped by the probability the model gave. If a model says "70%", those questions should resolve Yes about 70% of the time.

The closer a line hugs the dashed diagonal, the better calibrated the model is. Above the diagonal means underconfident, below means overconfident.
